MarkEdit 安装教程

用自己的 Apple ID 免费签名安装，全程约 10 分钟，不需要越狱。

先看这里：本教程使用苹果官方的「个人免费签名」机制。 App 装上后每 7 天需要续签一次（重新跑一次第 5 步即可，App 里的数据不会丢）。

准备工作

  1. 一台 iPhone 或 iPad（iOS 15 以上）
  2. 一台 电脑（Mac 或 Windows 都可以）
  3. 一根 数据线（首次连接必须用线）
  4. 一个 Apple ID（就是你在 App Store 下载软件用的账号）

方法一：Sideloadly最简单 · 推荐

适合：有电脑、想省事的用户。

  1. 在 iPhone 上打开下载页，点击 iPhone版下载，把 MarkEdit-unsigned.ipa 下载下来，通过「文件」App 或隔空投送、微信文件传输等方式传到电脑上。
  2. 在电脑上打开 sideloadly.io，下载并安装 Sideloadly。
    （Windows 用户还需要先安装苹果官网版的 iTunes 和 iCloud，不能用微软商店版。）
  3. 用数据线把 iPhone 连到电脑，iPhone 上弹出提示时点 「信任此电脑」。
  4. 打开 Sideloadly，把 .ipa 文件拖进窗口，在 Apple ID 一栏输入你的 Apple ID 邮箱。
  5. 点击 Start，按提示输入 Apple ID 密码（如果开了双重认证，按提示输入验证码），等待 1～2 分钟，出现 Done 即安装成功。
  6. 在 iPhone 上打开
    设置 → 通用 → VPN与设备管理
    点你的 Apple ID → 点 「信任」。
  7. 回到桌面，打开 MarkEdit，开始使用 🎉
7 天后打不开怎么办？重新执行第 3～5 步即可（不用删除 App，数据都在）。

方法二：AltStore可无线续签

适合：希望手机、电脑连同一 Wi-Fi 就能自动续签的用户。

  1. 在电脑上打开 altstore.io，下载安装 AltServer（Windows 同样需要官网版 iTunes + iCloud）。
  2. 数据线连接 iPhone 并「信任此电脑」。
  3. 运行 AltServer（Mac 在菜单栏、Windows 在右下角托盘），选择 Install AltStore → 选你的 iPhone → 输入 Apple ID 和密码。
  4. iPhone 上出现 AltStore 后，到 设置 → 通用 → VPN与设备管理 信任你的 Apple ID。
  5. 用 iPhone 的 Safari 打开下载页，点击 iPhone版下载 下载 IPA。
  6. 打开 AltStore → My Apps → 左上角 ＋ → 选择刚下载的 IPA，等待安装完成。
  7. 续签：保持电脑 AltServer 运行、手机电脑同一 Wi-Fi，打开 AltStore 点 Refresh All 即可。

方法三：SideStore手机独立续签

适合：平时不想开电脑的用户（首次配置稍麻烦，之后续签只靠手机）。

  1. 先用 AltServer 或 Sideloadly（见方法一/二）把 SideStore 装到 iPhone 上，官网：sidestore.io。
  2. 按 SideStore 引导登录 Apple ID，并安装 WireGuard、导入 SideStore 提供的 VPN 配置。
  3. 开启 WireGuard 的 VPN 开关，打开 SideStore 完成配对。
  4. 用 Safari 下载 MarkEdit IPA，在 SideStore 中点 ＋ 导入安装。
  5. 之后续签只需：打开 WireGuard VPN → 打开 SideStore → 点 Refresh。

常见问题

输入 Apple ID 密码安全吗？

Sideloadly / AltStore 会把账号密码直接发给苹果官方服务器用于签名，软件本身不存储。如果担心，可以专门注册一个备用 Apple ID 用于签名，或在苹果官网生成「App 专用密码」。

为什么 7 天就过期？

这是苹果对免费 Apple ID 的限制：免费签名有效期 7 天、同时最多装 3 个自签 App。付费开发者账号（$99/年）则是一年有效期。

续签后 App 里的文件会丢吗？

不会。只要不删除 App 图标，直接覆盖安装/续签，所有文档都保留。

提示「不受信任的开发者」怎么办？

到 设置 → 通用 → VPN与设备管理，点你的 Apple ID，选择「信任」。

安装时报错 / 闪退怎么办？

① 确认 iPhone 已「信任此电脑」；② 确认 Apple ID 密码正确（开了双重认证要输入验证码）；③ 换一根数据线或 USB 口；④ 重启 Sideloadly 和手机后重试。

有没有不用电脑的方法？

首次安装都需要电脑辅助一次。装好 SideStore 后，后续续签可以只用手机完成（见方法三）。
